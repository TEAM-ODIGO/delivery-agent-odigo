# 카드 이미지

결제수단 선택 화면에 보이는 카드 이미지를 여기에 넣는다. 파일 이름은 **결제수단 ID**로 짓는다.

| 파일 이름 | 결제수단 |
|---|---|
| `CARD001.png` | 요기요 신한카드 체크 |
| `CARD002.png` | 신한카드 구독 좋아요 |
| `CARD003.png` | 신한카드 Deep On Platinum+ |
| `LOCAL001.png` | 가상 지역화폐 (없으면 기본 모양) |
| `PRD-CARD-D.png` | KB국민 노리2 체크카드 (내 카드 추가로 들어오는 카드는 상품 ID로 짓는다) |
| `PRD-CARD-E.png` | 현대카드 ZERO Up |
| `PRD-CARD-F.png` | 요기요 삼성카드 |

- 확장자는 png, jpg, jpeg, webp, svg 중 아무거나 된다.
- 이미지 파일은 **세로형**(가로:세로 약 1 : 1.586, 신용카드를 세운 모양)으로 넣는다.
- 화면에는 기본으로 세로형으로 보여 준다. `frontend/.env`에 `VITE_CARD_IMAGE_LAYOUT=landscape`를 쓰면 이미지를 눕혀 가로형으로 보여 준다(개발 서버 재시작).
- 파일이 없으면 이름이 적힌 기본 카드 모양이 대신 보인다.
- 신한카드 이미지는 신한카드에 권리가 있다. 시연·내부 용도로만 쓰고, 공개 배포 전에는 사용 허가를 확인한다.
