# 카드 앞면 이미지 (첫 화면 카드 모달)

NFC 카드를 대면 뜨는 카드 모달의 앞면에 쓰는 이미지입니다. 아래 이름으로 넣으면 바로 반영됩니다.
확장자는 png, jpg, webp 중 하나면 됩니다 (png → jpg → webp 순서로 찾음).
파일이 없으면 신한카드 공식 카드 이미지(shinhancard.com)를 바로 불러오고, 그것도 안 되면 색 카드로 나옵니다.
인터넷이 안 되는 곳에서 시연할 때만 파일을 넣어 두면 됩니다.

| 파일 이름 | 가상카드 | 실제 상품 |
|---|---|---|
| `card-a.png` | CARD001 (PRD-CARD-A) | 요기요 신한카드 체크 |
| `card-b.png` | CARD002 (PRD-CARD-B) | 신한카드 구독 좋아요 |
| `card-c.png` | CARD003 (PRD-CARD-C) | 신한카드 Deep On Platinum+ |
| `local-a.png` | LOCAL001 (PRD-LOCAL-A) | 가상 지역화폐 (선택) |

- KB국민 노리2·현대카드 ZERO Up·요기요 삼성카드(내 카드 추가로 들어오는 카드)는 이 폴더가 아니라 `public/cards/PRD-CARD-D·E·F.png`를 같이 쓴다.
- 세로 카드 이미지는 그대로, 가로 카드 이미지는 자동으로 90도 돌려서 세로 카드 틀(54 : 85.6)에 맞춥니다.
- 카드 테두리 밖 여백이 없게 잘린 이미지가 가장 깔끔합니다 (여백이 있으면 틀에 맞게 잘려 보임).
- 카드 이미지는 신한카드의 자료입니다. 팀 내부 시연용으로 쓰고, 외부 공개·배포 전에는 사용 가능 여부를 확인하세요.
